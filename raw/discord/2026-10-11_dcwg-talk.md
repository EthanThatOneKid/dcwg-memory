speaking to the current team and asking for a handover

asking the team to get the current repo into a good state to be maintained (maybe they have some specific things that would make life a lot easier)

asking to pair code with some of the core team

using an llm to analyze the last x commits on the runtime to get a baseline for maintenance and produce a forecast
