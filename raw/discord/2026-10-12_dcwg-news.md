A long time ago, deno had an official way of writing FFI (not wasm!) bindings easier: https://github.com/denoland/deno_bindgen

This project is now revived under dodo, with a much better implementation inspired by https://github.com/mozilla/uniffi-rs / https://github.com/wasm-bindgen/wasm-bindgen
And with a better support for dodo/deno own dlopen features

It should make it much easier to bind dodo/deno to the system/rust ecosystem libraries for the features someone might want to use, e.g USB/Audio. Enjoy!
