**Summer** — 2026-11-10T14:53:05Z, edited 2026-11-10T14:57:48Z (`1569726600931708929`)

> ↳ replying to Varethiel: I wonder, why doesn't Ende support `bundle`?

<https://github.com/theende/ende/commit/f4cd06cd80a1d14af6d5b74230b766cfc86b76aa>
> The bundler downloaded esbuild through the npm registry machinery, which is being removed along with the rest of Node/npm compatibility. This removes the bundle subcommand, the unstable bundle feature, Ende.bundle, the ext/bundle crate, and compile's --bundle/--minify flags (whose main purpose was avoiding shipping node_modules). `ende compile` without those flags is unchanged.
Explains a bit, ende removed/s a bunch of NPM support, and esbuild still exists to use via other means. Deno had bundling, if I remember correctly they then removed it because it wasn't really needed, and then added it back only for convenience (it was either bundle or compile, can't remember which)

* <https://esbuild.github.io/api/#browser> if one doesn't mind fiddling with a npm-to-esm service online, this is an option to run it under ende (replacing the import with the esm service's url)
