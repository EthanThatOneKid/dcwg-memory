## A "Killer App Framework" (thread 1562291277209411675)

**SpaceMonkey** — 2026-10-21T18:56:59Z (`1562540223890460703`)

I don't recommend starting a new app framework; a lifelong project is correct.  One of the guiding principles of my Denext project (the app framework that I'm using AI to engineer) has been: don't reinvent; Denext follows the surface API for existing React, Next, etc. It's been a FAR larger undertaking than I originally planned, especially after going down the Deno forking rabbit hole. Having the well-documented surface API produces 10x better code from code generation. But it's still been seriously laborious getting Denext stable, tested, and secure. I suggest Dodo stay with a fork of Laufey, so we aren't changing Deno in a way that alienates existing Deno users.  Just like Denext, I don't have to sell anyone on a "new" framework... It's just a substantially better implementation. Like I've said, you can all use and ship my fork of Laufey if you choose to stay with that and want a considerably more mature version of it. 🙂
